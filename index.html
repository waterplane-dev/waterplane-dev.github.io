An IDE, rethought for the phone in the age of agentic coding.

The agent writes the code; what you need in your hand is the steering. waterplane drives the real Claude Code CLI on your own desktop, over Tailscale, and puts the workbench around it: files and diffs, commits and builds, the screenshots it makes, a queue and a schedule, and what every turn costs.

Try the demo· Install· How it compares

macOS, Linux, Windows via WSL2. Android app or web app; no iOS app yet. The demo runs entirely in your browser, best on a phone.

It is the CLI, not a copy of it

A small Node daemon on your desktop runs the actual claude binary in a terminal and streams that terminal to your phone. Because nothing is re-implemented, every slash command, plan and trust prompt, /btw and the context meter work as they do at the desk; choice boxes come up as buttons.

The phone talks to your desktop over your own tailnet. There is no waterplane server, no account and no telemetry.

Show it, don't describe it

Whatever Claude leaves in .claude/outbox/ shows up on the phone as a picture or a file, with a badge on the repo and a notification. Open a screenshot, circle the broken spot, type what to change, and the marked-up picture goes back into the prompt.

Ask Claude to build and run your app in a simulator, emulator, browser or on an attached phone, and the verified screenshot lands in that gallery. For Android work, the APK installs itself on your own phone.

When the usage limit hits, it carries on

The host sees the limit, waits for the reset and continues the session, reopening the conversation with --continue if the CLI exited. Retries are bounded, and there is an off switch per session and for the desktop.

To stop before the wall instead, give a session a budget in tokens, dollars or a share of the 5-hour or weekly window. The next send is held when it is reached, with your words kept.

Queue it now, or schedule it against the windows

A prompt sent while you are offline or while the session is busy waits in a queue and is typed in exactly once. Or post one for later: at a time, when the session goes quiet, after another one finishes, or two hours before the weekly reset to spend what is left.

Know what each turn costs

Every finished turn shows its tokens in, out and cached, priced at list price, and what the next turn will cost against starting fresh. The ledger splits a week by day, repo and model. It is all read off the CLI's own logs; where there is nothing to read, nothing is shown.

Repo health tracks what makes every request dearer over time: a CLAUDE.md that only grows, files past a thousand lines, the same files edited on every turn.

Also in the box: git diffs and commits, builds run without a session so they spend no tokens, push-to-talk, a fork from any turn, several desktops in one app, and plugins for buttons we did not think of.

Install

The daemon spawns claude, which can read, edit and run files on your machine, and there is no app login by default: the network is the boundary. It binds only loopback and your Tailscale IP. Read SECURITY.md before you install. Unofficial: not affiliated with or endorsed by Anthropic.

You need Claude Code installed and signed in, Tailscale on the desktop and the phone, and tmux 3.3 or newer (the installer offers it). The installer brings its own Node and verifies checksums:

curl -fsSL https://waterplane.dev/install.sh | sh

Or from source:

git clone https://github.com/waterplane-dev/waterplane.git
cd waterplane
npm ci
npm run doctor
npm run build
npm start

waterplane doctor says what is missing and what to type. The host prints its address; open it on the phone, or use the Android app from the latest release. Windows, Docker, HTTPS and the background service: the install guide.

How it compares

Reaching your agent from a phone is not new. Anthropic's Remote Control puts a running session in the Claude app, and Happy, Paseo and Orca put coding agents on a phone too. Remote Control and waterplane work side by side.

What is different here is the workbench around the session: everything on this page, plus a reader for the same session with markdown rendered and tool calls folded.

An agent that runs Claude Code for you is enough for "go do X, message me". We built this for the times you want to watch the session, answer its questions and read the diff before the commit.

We built waterplane to work on our own repos away from the desk. MIT licensed.
